# 免登录案例发现与名称搜索设计

## 目标

让位于企业内网或企业 VPN 网络边界内的内部员工，无需应用登录即可浏览当前生产线平衡改善案例，并以案例名称的部分关键词查找案例。

## 范围与边界

- 公开读者路径仅指免除应用内登录；部署环境仍必须受企业内网或 VPN 网络边界限制。
- 搜索只匹配案例名称（`title`），采用不区分大小写的包含匹配。
- 案例说明、分类和标签不参与搜索；分类与标签也不成为发布或查找案例的前提。
- SSO、企划人员的写入权限、案例详情和下载行为不在本次变更范围内。

## 方案

保留现有 `GET /api/ppts` 作为免登录的读者接口。未提供 `search` 时，它返回全部当前案例；提供非空 `search` 时，只返回 `title` 包含该关键词的案例。

前端搜索框将关键词传给该接口，不再用已加载的本地列表匹配案例说明。清空关键词时，重新请求完整案例列表。前端仍可保留展示已有案例元数据，但不新增分类或标签筛选要求。

## 测试与验证

新增 HTTP 集成测试，使用无授权请求验证：

1. 可获取案例列表；
2. 案例名称的部分关键词可命中该案例；
3. 仅存在于说明、分类或标签中的关键词不会产生搜索结果。

运行 TypeScript 检查和完整测试套件，确保生产启动路径未受影响。
